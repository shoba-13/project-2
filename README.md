🌿 InkSpace – Responsive Blog Application

✨ About the Project

InkSpace is a modern and responsive Blog Application developed using HTML, CSS, and JavaScript. It provides a simple platform where users can register, log in, create blog posts, and manage their stories.

🚀 Features

* 🏠 Home Page – Explore the latest blog posts.
* 🔐 Login Page – User login interface.
* 📝 Register Page – Create a new account.
* 📊 Dashboard – View and manage your blog posts.
* ✍️ Create Blog – Write and publish new stories.
* 📱 Responsive Design – Supports desktop, tablet, and mobile screens.
* 💾 Local Storage – Saves demo user and blog information in the browser.

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Visual Studio Code

⚙️ How to Run

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser.
4. Register a demo account.
5. Log in and explore the dashboard.
6. Create and publish your blog posts.
